# 🤖 ربات تلگرام فروش VPN

ربات تلگرامی برای فروش کانفیگ VPN با امکانات کامل.

## ✨ امکانات

- 🛒 **خرید سرویس جدید** - انتخاب پلن و پرداخت
- 🧪 **اکانت تست رایگان** - تست یک‌باره رایگان
- 📦 **سرویس‌های من** - مشاهده سرویس‌های فعال
- 💰 **کیف پول** - شارژ با ۳ روش:
  - 💳 درگاه پرداخت آنلاین
  - 🏧 کارت به کارت
  - 🎁 کد تخفیف
- 👥 **دعوت از دوستان** - لینک اختصاصی + بونس
- 📞 **پشتیبانی** - تیکت چت
- 📖 **آموزش** - راهنمای وارد کردن کانفیگ
- ⚙️ **پنل ادمین** - مدیریت کامل

## 🛠️ نصب و راه‌اندازی

### ۱. پیش‌نیازها

- Python 3.11+

### ۲. نصب وابستگی‌ها

```bash
cd vpn_bot
pip install -r requirements.txt
```

### ۳. تنظیم ربات

فایل `config.py` را باز کنید و مقادیر زیر را ویرایش کنید:

```python
BOT_TOKEN = "توکن_ربات_تلگرام"
ADMIN_ID = 123456789
```

> 💡 فقط دو فیلد بالا الزامی است. بقیه تنظیمات اختیاری هستند.

### ۴. اضافه کردن پلن‌های پیش‌فرض

```bash
python seed_products.py
```

> 💡 این دستور ۴ پلن فروش و ۱ اکانت تست اضافه می‌کند.

### ۵. اجرا

```bash
python bot.py
```

> 💡 دیتابیس SQLite خودکار ساخته می‌شود - نیازی به نصب PostgreSQL نیست!

```
├── requirements.txt        # وابستگی‌ها
├── database/
│   ├── engine.py           # اتصال دیتابیس
│   └── models.py           # مدل‌ها
├── handlers/

│   ├── buy.py              # خرید سرویس
│   ├── test_account.py     # اکانت تست
│   ├── my_services.py      # سرویس‌های من
│   ├── wallet.py           # کیف پول
│   ├── referral.py         # دعوت از دوستان
│   ├── support.py          # پشتیبانی + آموزش
│   └── admin/
│       ├── dashboard.py    # داشبورد ادمین
│       ├── orders.py       # مدیریت سفارشات
│       ├── products.py     # مدیریت پلن‌ها
│       └── users.py        # مدیریت کاربران + کارت به کارت
├── keyboards/
│   └── inline.py           # کیبوردهای inline
├── locales/
│   └── fa.py               # متون فارسی
├── states/
│   └── states.py           # FSM states
└── middlewares/
    └── auth.py             # احراز هویت
```

## 👨‍💼 دستورات ادمین

- `/admin` - باز کردن پنل ادمین

## 📝 نکات

- اولین کاربری که `/admin` را بزند، ادمین می‌شود (یا از `ADMIN_ID` در `config.py`)
- برای تحویل کانفیگ، ادمین باید لینک را دستی ارسال کند
- سیستم پرداخت آنلاین نیاز به اتصال به درگاه (زرین‌پال/آیدی پی) دارد
